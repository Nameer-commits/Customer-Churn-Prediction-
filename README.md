# Customer-Churn-Prediction-

Introduction:
This is a 5th Semester AI course Assignment of BS Computer Science Level in which we had to create a Machine Learning Model to predict if a customer is likely to churn or not, meaning if he/she is likely to leave or not. The Problem statement is as under

Statement:
The purpose of this assignment is to build a complete Customer Churn Prediction machine learning system. You will analyze customer information and train a model to predict whether a customer is likely to leave the telecom company (Churn = Yes) or remain with the company (Churn = No).
